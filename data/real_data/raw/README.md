# Real data drop zone

Put downloaded source files here. Do not rename away source identity. Keep original files unchanged.

- `usda_sweetpotato_chip_texture_fat.csv`: use the downloader script or Data.gov source page.
- `mendeley_frying_oil/`: download all three CSV files from the Mendeley page and place them in this folder.
- `mendeley_potato_frying_color/`: download the files from the Mendeley page and place them in this folder.

The application does not generate or fabricate real data. If a file is absent, it reports it as not acquired.
